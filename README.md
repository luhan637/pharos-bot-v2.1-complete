# Pharos Bot v2.1 - Complete Solution

## Hướng Dẫn Cài Đặt
1. Cài đặt NodeJS (v16+)
2. Chạy lệnh: `npm install`
3. Cấu hình ví trong `wallets.json` (copy từ `wallets.example.json`)
4. Điều chỉnh thông số trong `config.json`
5. Chạy bot: `npm start`

## Các Tính Năng Mới
- **GasManager**: Tự động tối ưu hóa phí gas theo thời gian thực.
- **UnifiedTxExecutor**: Xử lý giao dịch tập trung, tự động retry khi lỗi.
- **ContractHealthChecker**: Kiểm tra tình trạng contract trước khi tương tác.
- **GrandLine NFT Module**: Tự động mint và quản lý NFT.
- **Anti-bot Bypass**: Cơ chế giả lập hành vi người dùng nâng cao.
